# Java 09 – Projektet e preferuara

## Përshkrimi
Në këtë javë është implementuar funksionaliteti për shtimin dhe heqjen e projekteve nga lista e të preferuarave në aplikacionin Ndërtimtari.

## Funksionalitetet e realizuara
- Shtimi i një projekti te të preferuarat përmes ikonës së zemrës.
- Shfaqja e zemrës së mbushur kur projekti është i preferuar.
- Ruajtja e preferencave në databazën Neon.
- Marrja e projekteve të preferuara nga API.
- Heqja e projektit nga lista e të preferuarave përmes kërkesës DELETE.
- Parandalimi i regjistrimeve të dyfishta në databazë.
- Shfaqja e mesazheve për sukses ose gabim.

## Teknologjitë e përdorura
- Next.js
- React dhe TypeScript
- API Routes (GET, POST, DELETE)
- Neon PostgreSQL
- GitHub Authentication
