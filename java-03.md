# Java 3 – Projektet dhe faqet

## Prova 1

Hapat: E nisa aplikacionin dhe hapa faqen kryesore në shfletues.

Rezultati: U shfaq faqja Ndërtimtari me listën e projekteve për ndërtim shtëpie, ndërtim objekti afarist dhe renovim banese.

## Prova 2

Hapat: Nga faqja kryesore klikova te projekti “Ndërtim shtëpie” për t'i parë detajet.

Rezultati: U hap faqja e detajeve të projektit dhe kontrollova informacionet e shfaqura.

## Prova 3

Hapat: Hapa adresën /projekti/99 në shfletues për të testuar një projekt që nuk ekziston.

Rezultati: U shfaq mesazhi “Projekti nuk u gjet”, duke treguar se projekti me atë ID nuk ekziston.
